I measure before I change anything, and I publish the method with the number. My work, writing and tools are at **[debarshidas.dev](https://debarshidas.dev)**.

## Open source

- **[system-one-bench](https://github.com/DarkStark9000/system-one-bench)**: reproducible latency benchmarks for System 1 decision models, starting with Laya. One command times every backend your machine has, splits each call into phases, counts its GPU kernels, and checks that every backend gives the same answers.
- **[gpu-specs](https://github.com/DarkStark9000/gpu-specs)**: cited GPU specifications for NVIDIA and AMD. Every number carries its vendor source and the vendor's own words.

## Tools

- **[KV cache calculator](https://debarshidas.dev/kvcalc)**: reads any public Hugging Face model's config in your browser, then sizes its KV cache, the weights per GPU, and how many requests fit.
